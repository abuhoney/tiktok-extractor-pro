🔐 إدارة جلسة TikTok (sessionid)

        

          لتفعيل التفاعلات المتقدمة (التعليق، الرسائل)، تحتاج إلى توفير sessionid من متصفحك بعد تسجيل الدخول إلى TikTok.
          يتم حفظه بشكل دائم في GitHub (في data/sessions/)، ويُستخدم فقط عند الطلب.
        


        


        

          

            
            
            اسم المستخدم الخاص بك على TikTok (بدون @)
          


          

            
            
            افتح tiktok.com في المتصفح → F12 → Application → Cookies → انسخ قيمة sessionid
          


          

            كوكيز إضافية (اختياري لكن مُوصى به)
            

              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

          


          
          
          
        


        


        

          📚 كيف أحصل على sessionid؟ (خطوات مفصّلة)
          
    
            
  1. افتح متصفح Chrome أو Firefox على الكمبيوتر
    2. 
            
  2. اذهب إلى tiktok.com وسجّل دخولك بحسابك
    3. 
            
  3. اضغط F12 لفتح DevTools
    4. 
            
  4. اذهب إلى تبويب Application (أو Storage في Firefox)
    5. 
            
  5. من القائمة الجانبية: Cookies → https://www.tiktok.com
    6. 
            
  6. ابحث في عمود Name عن:
              
      
                
    • sessionid — انسخ القيمة من عمود Value
      • 
                
    • ttwid — انسخه أيضاً (اختياري لكن مُوصى به)
      • 
                
    • msToken — يُحدّث باستمرار، انسخ أحدث قيمة
      • 
                
    • sid_tt — اختياري
      • 
              
    
            
    7. 
            
  7. الصق القيم في الحقول أعلاه واضغط "حفظ الجلسة"
    8. 
            
  8. ستُحفظ الجلسة في GitHub في data/sessions/<username>.json
    9. 
          

          

            ⚠️ تنبيه أمني: sessionid يمنح وصولاً كاملاً لحسابك. لا تشاركه مع أحد. سيُحفظ في GitHub repo الخاص بك (تأكد أنه خاص) أو في Render كمتغير بيئة.
